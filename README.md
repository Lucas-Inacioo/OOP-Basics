# O que é este repositório
Este repositório foi criado como parte da monitoria das disciplinas Algoritmos e Estruturas de Dados/Programação Orientada a Objetos com a finalidade de implementar soluções para exercícios pré-determinados, além de sugestões de qualidade de código.

Não serão dadas respostas/implementações para todos os exercícios das listas, apenas exercícios selecionados e que façam sentido com o objetivo da monitoria, caso tenha dúvidas sobre as implementações dispostas ou exercícios que não foram selecionados, envie-as para o meu whatsapp, ou para os que não o tiverem, para o e-mail lucasinacio2003@usp.br

# Por onde começar?
Recomendo começar pela `Lista0` que, apesar de não existir realmente uma lista 0, irá revisar alguns conceitos de orientação a objetos, explicar a estrutura que será utilizada para as soluções propostas e introduzir sugestões de estilo para suas implementações.

## Estrutura do repositório
O repositório está disposto na seguinte estrutura:
- Lista0 
- Lista1 
- Lista2 
- Lista3 
- Lista4
- PDFs

Em `Lista0` serão introduzidos conceitos de orientação a objetos,

Em `Lista1`, `Lista2`, `Lista3` e `Lista4` estão dispostas as implementações e respostas para os exercícios selecionados.

Por fim, em `PDFs` são encontradas as listas de exercícios supracitadas.

Em cada uma das seções você encontrará arquivos/diretórios com os prefixos:
- GUIDE
- EXERCISE-{ExerciseNumber}
- OPTIONAL

Arquivos marcados com o prefixo `GUIDE` são arquivos markdown que fornecem instruções em texto sobre os exercícios daquela seção, servindo como fundamentação teórica.

Diretórios marcados com o prefixo `EXERCISE-{ExerciseNumber}` contêm arquivos Java/markdown que fornecem a implementação ou resposta para o exercício de número `ExerciseNumber` da respectiva lista.

Por fim, arquivos marcados com o prefixo `OPTIONAL` são leituras opcionais em markdown, mas recomendadas, incluindo discussões que não são diretamente relacionadas aos exercícios, mas que podem ser úteis para o desenvolvimento de habilidades de programação e resolução de problemas.
